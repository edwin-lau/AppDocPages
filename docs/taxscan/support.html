Getting started

  • Scan: capture paper with the camera or import from Files / Photos.

  • Toolkit: merge, split, extract, compress, sign, or set an open password — on device.

Common questions

Where are my PDFs stored?

On your device in the TaxScanBag library and drafts. See the Privacy Policy.

Do you upload my documents?

No. Scanning, OCR, merge/split/extract, and export preferences stay local. There is no developer upload backend.

Camera or photo access was denied

Open iOS Settings → TaxScanBag and allow Camera / Photos if you want to scan or import images. You can still import from Files.

Restore purchases

Open the Lifetime unlock screen and tap Restore, signed in with the same Apple ID used to buy. TaxScanBag has no subscriptions — only a one-time Lifetime unlock.

Refunds

Purchases are handled by Apple. Request a refund at reportaproblem.apple.com.

常见问题

我的 PDF 存在哪？

在本机 TaxScanBag 资料库与草稿中，详见隐私政策。

会上传我的文档吗？

不会。扫描、OCR、合并/拆分/抽取和导出偏好都在本机完成，没有开发者上传后端。

相机或相册权限被拒绝

到 iOS「设置 → TaxScanBag」开启相机 / 照片即可。也可以继续从「文件」导入。

恢复购买

用购买时的同一 Apple ID，打开终身解锁界面并点「恢复购买」。TaxScanBag 没有订阅，只有一次性终身买断。
